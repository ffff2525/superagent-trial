关于本项目

superagent-trial 是一个小型演示仓库，核心是命令行脚本 scripts/countdown.py：接收正整数 N，逐行打印 N 到 1， 最后输出 Liftoff!；非法输入以退出码 2 报错，并支持 --help。测试位于 tests/，使用 pytest。

本页面是它的纯静态演示，由 GitHub Pages 从 docs/ 目录部署， 不依赖任何前端框架或外部资源。
